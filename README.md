# QAH Git Marketplace

This repository is a plugin registry for **Quantum Analysis Helper**, managed
by the *Git Plugin Marketplace* plugin.

Layout:

```text
index.json                              catalog
plugins/<id>/manifest.json              plugin manifest
plugins/<id>/README.md                  optional description
plugins/<id>/<version>/<id>-<version>.qplugin.zip
```

Do not edit `index.json` by hand while a publish is running. The plugin writes
the catalog and the ZIP in one Git commit.

Repository: `ADOBApps/qah-git-marketplace` (branch `master`)

Generated by QAH Git Plugin Marketplace.
